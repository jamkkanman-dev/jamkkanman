# 잠깐만

차가 멈추는 순간(기어 P·안전벨트 풀림·문 열림), 그 자리가 소화전·횡단보도·어린이보호구역 같은 주정차 금지구역이면 내리기 전에 한 번 음성으로 알리고 가까운 공영주차장으로 안내하는 Pleos Connect 차량 앱입니다.

- 데이터 범위: 서울 강남구 전체 (금지구역 15,423곳, 단속 CCTV 358대). 시연 지점은 대치동 학원가의 실제 지점
- 제출 APK: [`apk/잠깐만_잠깐만_release.apk`](apk/) (release 빌드, 서명 포함)

## 주요 기능

| 기능 | 내용 | 사용한 Pleos / 차량 API |
|---|---|---|
| 멈추는 순간 감지 | 기어를 P로 바꾸거나, 멈춘 채(차속 3km/h 미만) 안전벨트가 풀리거나, 문이 열리면 그 자리를 바로 확인. 안전벨트는 문이 열리기 몇 초 전에 오는 신호라 기어 D에 브레이크만 밟고 내려 주는 정차도 더 일찍 잡음. 벨트가 풀려 멈춘 경우는 “문 열기 전에 확인해 주세요”로 시작하고, 옮길 때는 벨트를 다시 매라고 안내(벨트를 푼 채 차를 움직이지 않게). 주행 중(5km/h 이상)에는 화면을 가리고 음성으로만 안내 | Android Automotive `GEAR_SELECTION`(Pleos SDK에 같은 API가 없어 Pleos 안내대로 표준 속성 사용)·`PERF_VEHICLE_SPEED`(차속), Pleos Vehicle SDK `Seat`(안전벨트)·`Brake`·`Door`. Pleos 신호는 모두 `check…Capabilities`로 차가 지원하는지 먼저 확인한 뒤 구독 |
| 금지구역 확인 | 소화전 5m, 교차로 모퉁이 5m(교차로 가장자리에서 측정), 버스정류장 10m, 횡단보도 10m(실제 횡단보도 모양의 테두리에서 측정), 어린이보호구역 안인지 확인(도로교통법 제32조 등). 과태료와 몇 m만 옮기면 되는지까지 안내. 주민신고는 안전표지·정지선 등 조건이 있어 앱은 '신고된다'고 하지 않고 '주정차 금지구역'으로만 안내. 소화전 과태료는 4만 원으로 셈하고 '안전표지가 있으면 8만 원'을 덧붙임 | 강남구 공공데이터 (아래 데이터 출처) |
| 단속 위험 알림 | 단속 CCTV가 50m 안이면 경고에 덧붙이고, 반경 50m 안 실제 단속 건수(2025년 10~12월)를 보여 줌. 금지구역이 아니어도 단속이 잦은 곳이면 노란 선을 확인하라고 안내 | 서울시 단속 CCTV 위치·불법주정차 단속 정보 |
| 한 번만 음성 안내 | 같은 자리에서는 다시 말하지 않음. 운전 중에는 화면 대신 음성 | Pleos TextToSpeech SDK (기기 내 합성) |
| 세울 곳 안내 | 가장 가까운 공영주차장을 보여 주고 버튼 한 번으로 길 안내 또는 경유지 추가 | Pleos NaviHelper SDK |
| 도착 전 안내 | 목적지 앞이 금지구역이면 도착 700m 전에 음성으로 미리 알리고, 설정(기본 켜짐)대로 세울 곳을 경유지로 바로 추가. 주행 중 조작 없음. “경유지로 넣을까요?”라고 묻고 듣는 기능(SpeechToText)도 만들었지만, 에뮬레이터에서 인식이 시작되지 않아 확인 전까지 꺼 둠(`VoiceAnswer.ASK_BY_VOICE`) | Pleos NaviHelper SDK (SpeechToText SDK는 기본 꺼짐) |
| 정밀 위치 | 멈춘 자리는 Pleos 정밀 위치(GPS·차량 센서 결합)를 먼저 쓰고, 없으면 내비·기기 GPS 위치를 씀. 내비 위치는 도로 가운데에 맞춘 값이라 길가에 선 차의 자리는 정밀 위치가 더 가까움 | Pleos FusedLocation SDK |
| 음성으로 묻기 | "여기 세워도 돼?", "근처에 세울 데 어디야?", "이번 달 과태료 얼마 아꼈어?"를 말로 물으면 답함 | Pleos Gleo AI 연동 형식(`assets/schema.json`) 작성, Pleos 승인 전이라 같은 요청을 adb로 보내 확인 |
| 이번 달 아낀 과태료 | 알림을 듣고 금지구역 밖으로 옮겨 세웠을 때만 그 자리의 과태료를 더함 (실제 단속 여부와 관계없이 피한 최대 금액) | 앱 내부 기록 |
| 정차 수요 기록 | 운전자가 동의했을 때만, 정확한 위치 대신 약 50m 칸·시간대·요일만 차 안에 저장 (지자체 안심 승하차 구역 설계용). 지금은 밖으로 보내지 않음. 지자체에 보내려면 위치정보법상 신고·동의 절차가 필요 | 앱 내부 기록 |
| 지도 | 직접 그리는 오프라인 지도. 입체(3D)·평면(2D) 전환, 내 차 주변 금지구역과 세울 곳 표시 | 국토교통부 표준노드링크 (+ 시연용 빌드는 행정안전부 도로명주소 도형) |

화면은 Pleos Connect 디자인 가이드(Light 테마 색·타이포그래피, 1~2초 안에 읽히는 정보량)를 따릅니다. 가로 화면은 지도와 안내를 나란히, 세로 화면은 지도 위·안내 아래로 배치합니다. 세로 화면은 Pleos 공식 폼 팩터 테스트(FormFactorConsole, Connect-S 12.9" Portrait · 628×855dp)에서 요소가 잘리거나 겹치지 않는 것을 확인했습니다.

## 실행 방법

1. **개발 환경**: Android Studio와 Pleos Connect Emulator v2.1.0을 설치하고 AVD를 만듭니다. ([Pleos Connect Emulator 설정](https://document.pleos.ai/docs/connect/guide/getting-started/application-development/configure-pleos-connect-emulator))
   - AVD 부팅 옵션은 반드시 **Cold boot**로 둡니다. Quick boot에서는 차량 신호(VHAL)를 쓸 수 없습니다.
2. **열기**: 이 저장소를 내려받아 Android Studio에서 엽니다.
3. **실행**: 실행 대상을 `Pleos Connect v2.1.0`으로 고르고 `app`을 실행합니다.
   - APK로 설치할 때: `adb install -r apk/잠깐만_잠깐만_release.apk` (개발용 앱이 깔려 있으면 서명이 달라 먼저 `adb uninstall dev.jamkkanman.app`)
4. **시연 지점 고르기**: 앱 오른쪽 위 `시연` → `학원가 버스정류장`, `학원가 횡단보도`, `교차로 모퉁이`, `단속 잦은 곳` 등 대치동 지점을 누릅니다. (금지구역 데이터는 서울 강남구만 들어 있어, 옆 구로 넘어가면 "확인 범위 밖"으로 안내합니다.)
5. **차량 신호 보내기** (Pleos Connect Virtual Console)
   ```
   adb forward tcp:8088 tcp:8088
   ```
   PC 브라우저에서 `http://127.0.0.1:8088/` → `Emulation Controls`
   - `Gear Selection`: D → P
   - `Door Position`: Front left → Open
   - 안전벨트: Virtual Console에 조작 항목이 없어, 앱의 `시연` → `안전벨트 풀림`을 누르면 뒷좌석 벨트를 채웠다가 푸는 신호를 그대로 넣습니다.
   - 차속: Virtual Console 화면에는 없지만 같은 서버로 보낼 수 있습니다. 터미널에서 아래를 실행하면 30km/h로 달리다 약 4초에 걸쳐 멈춥니다 (주행 중 화면 가림 → 정차 확인).
     ```
     curl -X PUT "http://127.0.0.1:8088/vehicle/controls?speed=30"
     ```
   - 도착 전 안내: `시연` → `도착 전 안내`를 누르면 첫 번째 시연 지점을 목적지로 두고 남은 거리 500m일 때의 안내를 냅니다. 설정의 '도착 전에 세울 곳을 경유지로'가 켜져 있으면 세울 곳을 경유지로 넣고 그렇게 말합니다 (내비가 연결되지 않으면 거리만 알려 줌).
   - 신호 없이 보려면 앱의 `멈춤 신호` 버튼을 눌러도 됩니다. 같은 자리 안내를 다시 들으려면 `초기화`.

### 차량 신호 확인 결과 (Virtual Console)

| 신호 | 사용 API | 결과 |
|---|---|---|
| 기어 P | Android Automotive `GEAR_SELECTION` | 동작 확인 |
| 문 열림 | Pleos Vehicle SDK `Door.registerDoorPosition` | 동작 확인 |
| 차속 | Android Automotive `PERF_VEHICLE_SPEED` | 신호 확인 앱(probe)에서 값 수신 확인, Virtual Console 서버(`/vehicle/controls?speed=`)로 값 변경 확인 |
| 브레이크 | Pleos Vehicle SDK `Brake.registerBrakePedalStatus` | 신호 확인 앱(probe)에서 값 수신 확인, Virtual Console `Brake Pedal`로 변경 |
| 안전벨트 풀림 | Pleos Vehicle SDK `Seat.registerSeatBeltBuckledState` | 에뮬레이터 차량 설정(VHAL)에 `SEAT_BELT_BUCKLED`는 있으나 Virtual Console에 조작 항목이 없고 서버도 값을 받지 않음 → 앱 `시연` 줄의 `안전벨트 풀림` 버튼으로 같은 신호 흐름을 재현 |
| 비상등 | ① Android Automotive `HAZARD_LIGHTS_STATE` ② Pleos `TurnSignal` ③ Pleos `Safety` 경고등(Telltales) | 3rd party 앱에는 신호가 열려 있지 않음 (①은 시스템 앱 전용 권한 `CAR_EXTERIOR_LIGHTS`, ②는 비상등 때 값이 바뀌지 않음, ③은 실시간 구독이 시스템 앱 전용 권한이고 조회도 거부됨) |

비상등 대신 **안전벨트 풀림**으로 '내려 주는 정차'를 잡습니다. 달리는 중에 푼 것과 구별하려고 차가 멈춰 있을 때(차속 3km/h 미만, 또는 풀린 뒤 15초 안에 멈출 때)만 정차로 봅니다. Pleos SDK에는 차속 API가 없어 기어와 같은 방식으로 Android Automotive 표준 차속 속성을 쓰고, 차속을 못 받는 차에서는 기어 P·N·브레이크로 판단합니다 (`core/StopEngine.kt`). 경고등 조회(3rd party 권한 `CAR_SAFETY`)는 차에서 허용되면 비상등도 바로 쓰도록 남겨 두었고, 거부되면 한 번만 시도하고 멈춥니다 (`car/VehicleWatcher.kt`).

### GPS 오차 시험 (`GpsNoiseTest`)

대치동 학원가 반경 2km 안 실제 금지구역 2,904곳(어린이보호구역 제외)에서 무작위로 고른 구역의 중심에서 0~(반경+15m) 떨어진 '진짜 위치'를 만들고, 동서·남북으로 표준편차 σ인 오차를 더한 '잡힌 위치'로 판단했습니다. 정확도 값은 1.5σ로 넣었고, 구역 경계 근처만 골라 뽑아 가장 어려운 경우를 본 것입니다. 오차마다 약 3,000번, 씨앗값을 고정해 매번 같은 숫자가 나옵니다.

| σ | 진짜 금지구역 안: 확실 경고 / 가능성 / **놓침** | ('가능성' 단계가 없을 때 놓침) | 진짜 밖(경계 15m 안): **확실 경고(오경보)** / 가능성 / 조용 |
|---|---|---|---|
| 2m | 92.8% / 4.7% / **2.6%** | 7.2% | **6.9%** / 8.9% / 84.2% |
| 3m | 87.8% / 8.0% / **4.2%** | 12.2% | **9.6%** / 13.4% / 77.0% |
| 5m | 77.4% / 14.1% / **8.5%** | 22.6% | **15.1%** / 20.7% / 64.2% |

- '가능성' 단계(GPS 오차의 절반, 최대 5m 여유)가 놓침을 약 3분의 1로 줄입니다 (σ=3m에서 12.2% → 4.2%).
- 오경보는 금지구역 경계 바로 바깥(15m 안)에서만 생기며, 이 시험은 그런 위치만 뽑았기 때문에 실제 주행에서의 비율보다 높게 나옵니다.
- 공공데이터 자체의 위치 오차(시설 좌표와 실제 위치의 차이)는 이 시험에 들어 있지 않습니다.

## Gleo AI 음성 연동

[Pleos App Integration Guide](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/deliver-schema)대로 `app/src/main/assets/schema.json`에 음성으로 부를 수 있는 기능 3개를 적었습니다 (가이드 상한 3개).

| 기능 (schema 이름) | 방식 | 하는 일 | 이렇게 물으면 |
|---|---|---|---|
| `CHECK_PARKING_HERE` | activity | 지금 자리가 금지구역인지 다시 확인하고 과태료·옮길 거리·가까운 세울 곳을 음성으로 안내 | "잠깐만, 여기 세워도 돼?" |
| `FIND_LEGAL_PARKING` | activity | 가장 가까운 공영주차장으로 길 안내 시작 (NaviHelper) | "근처에 세울 데 어디야?" |
| `GET_SAVED_FINES` | service | 화면을 열지 않고 이번 달 아낀 과태료·알림 횟수를 돌려줌 | "이번 달 과태료 얼마 아꼈어?" |

- 결과는 `ai.pleos.playground.intent.action.APP_ACTION_RESPONSE` 방송으로 돌려줍니다. 가이드대로 `message`는 영어 한 문장, `data`는 JSON 배열 문자열입니다 (`car/GleoBridge.kt`).
- 앞의 두 기능은 앱이 한국어 음성으로 직접 답하므로 `mode: "silent"`로 Gleo가 겹쳐 말하지 않게 했습니다. `GET_SAVED_FINES`는 Gleo가 `data`를 보고 답합니다.
- schema는 Pleos 검토·승인 뒤에 Gleo AI에서 쓸 수 있어, 에뮬레이터에서는 Gleo가 보내는 것과 같은 Intent를 adb로 보내 세 기능 모두 응답이 돌아오는 것을 확인했습니다.
  ```
  adb shell am start -a CHECK_PARKING_HERE -p dev.jamkkanman.app --es ACTION_PARAM '{}'
  adb shell am start -a FIND_LEGAL_PARKING -p dev.jamkkanman.app --es ACTION_PARAM '{}'
  adb shell am broadcast -a GET_SAVED_FINES -p dev.jamkkanman.app --es ACTION_PARAM '{}'
  adb logcat -s Jamkkanman
  ```
  예: 학원가 버스정류장에서 `CHECK_PARKING_HERE` →
  `{"functionName":"CHECK_PARKING_HERE","status":"success","message":"Stopping here is prohibited because the car is within 10 m of a bus stop, and the fine is 40,000 won.","mode":"silent","data":"[{\"stopAllowed\":false,\"zoneType\":\"bus stop\",\"distanceM\":3,\"fineWon\":40000,\"certain\":true,\"moveM\":8,\"parkingName\":\"도곡로421 공영주차장\",\"parkingDistanceM\":17}]"}`

## 지도

- **기본 (저장소·제출 APK)**: 국토교통부 표준노드링크 도로망을 실제 차로 폭에 맞춰 그립니다.
- **시연용 빌드**: 행정안전부 도로명주소 도형(건물·실폭도로·하천·공원)을 함께 그립니다. 이 자료는 수령 조건상 국외 반출이 금지되어, 해외 서버인 GitHub 저장소와 제출 APK에는 넣지 않았습니다.
  - 직접 쓰려면 [주소기반산업지원서비스](https://business.juso.go.kr)에서 자료를 신청해 받은 뒤 `tools/build_basemap.py`로 `app/src/debug/assets/basemap_daechi.json`을 만들면 debug 빌드에만 들어갑니다.
- **입체(3D) 보기**: 비스듬히 내려다보는 원근 투영으로 건물을 세워 그립니다. 건물 도형에는 층수 정보가 없어 높이는 바닥 넓이로 정한 표현이며 실제 층수가 아닙니다.

## 지자체용 정차 수요 지도 (시제품)

`dashboard/index.html`을 브라우저로 열면 됩니다 (인터넷 연결·설치 필요 없음). 단속이 반복되는데 200m 안에 공영주차장이 없는 강남구 100m 칸을 단속 건수 순으로 10곳 골라 '안심 승하차 구역 후보지'로 보여 줍니다.

- 데이터: 앱에 들어 있는 공공데이터만 씁니다 (서울시 불법주정차 단속 정보 2025년 10~12월 중 강남구 위치 기록 24,138건, 공영주차장, 어린이보호구역, 표준노드링크 도로). 만드는 방법: `python3 tools/build_demand_map.py` → `dashboard/demand.js`
- 강남구 위치 단속 기록의 47%가 상위 10% 칸(100m)에 몰려 있어, 승하차 구역을 몇 곳만 골라 만들어도 효과를 볼 수 있는 구조입니다.
- 실제 서비스에서는 여기에 잠깐만 사용자가 동의한 정차 기록(약 50m 칸·시간대·요일, 앱 설정 '정차 수요 지도에 익명으로 보태기')이 더해집니다.

## 수익 모델 계산 (가정)

기획서 6번의 금액 계산입니다. 모든 값은 가정이며, 시범 운영 결과로 다시 계산합니다.

### 예상 MAU

탑재 차량 수 × 설치율 × 월간 활성률(70%, 가정).

- 탑재 대수(가정): Pleos Connect는 2026년 2분기 신차부터 적용, 2028년 누적 약 700만 대(전 세계, 산업일보 2025.3.31). 현대차·기아 국내 판매 비중 약 17%(2024년 국내 124만 5천 대 / 전 세계 723만 대, 더팩트 2025.1.3)로 보면 국내 약 120만 대이고, 그중 1/3인 40만 대만 3년 차 대상으로 잡았습니다.
- 설치율: 제조사 커넥티드 서비스도 운전자 76%가 가입하지 않았다고 답한 조사(Smartcar, 2025 State of Connected Car Apps, 미국·유럽 운전자 1,000명 이상)를 참고해 낮게 잡았습니다. 유료 구독 조사라 무료 앱 설치율과 같은 지표는 아닙니다.
- 월간 활성률과 3개월 유지율(70%)은 근거가 있는 값이 아니라 가정이며, 시범 운영에서 측정합니다.

| 시나리오 | 설치율 | 1년 차 (탑재 10만 대) | 3년 차 (누적 40만 대) |
|---|---|---|---|
| 기준안 | 10% | 약 7,000명 | 약 2만 8천 명 |
| 보수안 | 5% | 약 3,500명 | 약 1만 4천 명 |

- 횡단보도는 실제 모양(면) 5,316곳을 넣어 테두리에서 10m 안인지 잽니다. 모양 데이터(2021)에 없는 새 횡단보도 573곳은 2026년 위치 데이터의 점에서 10m로 판단합니다. 모양 데이터의 상태코드 중 정의서에 없는 값은 2026년 위치 데이터에도 있을 때만 씁니다 (`tools/add_crosswalks.py`).
- 교차로 모퉁이는 도로교통법 제32조 제2호("교차로의 가장자리나 도로의 모퉁이로부터 5미터 이내")대로 교차로 가장자리에서 5m를 잽니다. 교차로 모양은 공식 도형이 없어 표준노드링크로 추정합니다 (`tools/add_corners.py`).
  - 교차로(노드 유형 101)에서 만나는 일반도로마다 방향과 폭(방향별 차로 수 합 × 3.0m, 「도로의 구조·시설 기준에 관한 규칙」 제10조 도시지역 최소 차로 폭)을 구하고, 이웃한 두 도로의 연석선이 만나는 점(모퉁이)을 이어 교차로 영역을 만듭니다.
  - 왕복 분리 도로의 큰 교차로는 차도마다 노드가 따로 있어, 이름이 같은 노드를 하나로 묶어 감싸는 영역을 씁니다.
  - 표준노드링크에 없는 골목길 교차로는 아직 들어 있지 않습니다.
- 단속 기록은 개별 기록과 주소를 넣지 않고 25m 칸별 건수만 넣었습니다 (`tools/add_enforcement.py`). 반경 50m 안 단속이 석 달에 30건 이상(대치동 주변 기준 상위 약 25%)이거나 단속 CCTV가 50m 안이면 '단속이 잦은 곳'으로 봅니다.
- 노란 선(황색 실선·점선)처럼 지자체가 지정한 금지 구간은 좌표가 있는 공개 데이터가 없어 (전국주정차금지(지정)구역표준데이터는 위치가 글로만 제공됨), 단속이 잦은 곳에서는 노란 선을 직접 확인하라고 안내합니다.
- 데이터 가공 도구(`tools/`)는 엑셀·CSV를 읽는 `build_zones.py`(pandas)를 빼면 외부 라이브러리 없이 좌표 변환(GRS80 횡축 메르카토르 → 위도·경도)까지 직접 처리합니다. 순서: `build_zones.py` → `add_crosswalks.py` → `add_corners.py` → `build_roads.py` → `add_enforcement.py`
